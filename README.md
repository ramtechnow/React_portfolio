## ✨ Features & Highlights

- 🎨 **UI/UX Pro Max Design System**: Engineered using curated typography (**Archivo** for headings, **Space Grotesk** for body) and custom CSS design tokens.
- 🌓 **Dynamic Dual-Theme**: Seamless Dark/Light mode toggle with persistence via `localStorage` and system theme detection.
- 🔮 **Glassmorphism & Neon Effects**: Premium translucent headers, neon border glow highlights, and glowing card states (`hover:shadow-glow`).
- 🖱️ **Custom SVG Vector Cursor**: Smooth desktop cursor with reactive hover state fill transitions over clickable targets.
- ⚡ **Interactive Motion & Scroll Reveals**: Powered by **Framer Motion** for spring physics entrance, typewriter role cycling, and scroll-triggered animations.
- 📱 **Mobile-First Responsive Layout**: Containment-safe navigation, touch-friendly mobile menu drawer, and fluid grid column adjustments.
- 💼 **Categorized Showcase**:
  - **Hero**: Animated greeting, typewriter roles, glowing social links, direct resume download & contact CTA.
  - **Experience & Education**: Timeline view of corporate experience and academic background.
  - **Technical Skills**: Organized pill badges across Frontend, Backend, Cloud & Automation, and Soft Skills.
  - **Featured Projects**: Showcase with preview cards, tech tags, and React Portal modal for in-depth specs.
  - **Certifications**: Verified credentials display with verification links.
  - **Contact**: Interactive form and contact details card.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/ramtechnow/React_portfolio.git
   cd React_portfolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

4. **Build for Production**
   ```bash
   npm run build
   ```

## 🌐 Deployment

This project is deployed to **Firebase Hosting**. To deploy your own build:

```bash
# Log in to Firebase CLI
npx firebase login

# Build the project
npm run build

# Deploy to Firebase Hosting
npx firebase deploy
```
